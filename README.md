# 局域网网盘

一个简单的局域网私有云盘，基于 Django 写的。在公司或家里的局域网里，几台设备都能访问，方便传文件。

> **注意**：本项目已经全面重构，建议使用最新版本。

## 功能

- 用户注册登录，支持密码重置
- 上传下载文件，没有类型限制（单个文件最大 10GB）
- 创建/删除文件夹，面包屑导航
- 按文件名搜索
- 分享文件，可以设密码和有效期
- 图片 / 视频 / PDF / RAW 格式在线预览（NEF、CR2、ARW 等）
- 浅色 / 深色两套主题，可一键切换并记住选择
- 手机端也能用，响应式布局 + 移动端侧边栏
- 管理员用户管理：账号冻结（仅可登录预览，不可下载/上传/分享）、网盘配额控制、容量统计、删除用户、设为管理员

## 快速开始

需要 Python 3.8+。

```bash
# 安装依赖
pip install -r requirements.txt

# 初始化数据库（会自动给已有用户建配额档案）
python manage.py migrate

# 创建管理员（管理员登录后左侧会出现“用户管理”入口）
python manage.py createsuperuser

# 启动服务
python manage.py runserver 0.0.0.0:8000
```

Windows 用户也可以直接双击 `start_server.bat`，一键搞定虚拟环境、依赖安装、迁移和启动。

然后浏览器打开 `http://localhost:8000` 就能用了。局域网其他设备访问的话，换成你电脑的 IP 就行。

首次使用需要先注册一个账号。

可选：复制 `.env.example` 为 `.env` 来覆盖默认配置（时区、上传大小等）。

## 管理员说明

- 管理员（`is_staff`）登录后，左侧导航栏会出现“用户管理”入口，地址 `/manage/users/`。
- 冻结账号：仍可登录和预览，不可下载原文件、上传、新建/删除、创建分享。
- 配额：新用户默认 10GB；设为 0 或留空表示不限额；上传时整批校验，超额整批拒绝。
- 不能对自己执行冻结/删除/改角色，也不能动超级管理员。

## 项目结构

```
lan_drive/
├── drive/          # Django 项目配置
├── accounts/       # 用户登录注册、配额档案、用户管理后台
├── storage/        # 文件管理（上传、下载、删除、预览）
├── share/          # 文件分享
├── search/         # 文件搜索
├── templates/      # HTML 模板
├── docs/           # 接口文档与改造指南
├── media/          # 上传的文件存这里（不入库）
├── static/         # 样式、JS 等静态资源
├── .env.example    # 环境变量示例
└── start_server.bat  # Windows 一键启动脚本
```

## 用到的库

- Django 4.x
- Bootstrap 5（前端样式）
- django-crispy-forms + crispy-bootstrap5（表单）
- Pillow、rawpy、imageio、numpy（图片/RAW 处理）
- SQLite（数据库）

## 说两句

这项目主要是为了方便（局域网环境/内网穿透环境）互相传文件，不需要搭什么复杂的服务。功能够用，也没什么花里胡哨的东西。有什么问题直接提 issue 就好。

# 局域网网盘系统 V1.5 更新日志
## 版本: V1.5_26/03/20
## 发布日期: 2026年3月20日

---

## 🎯 版本概述

V1.5版本主要实现了对RAW格式照片的预览支持，同时修复了多个前端显示问题，提升了系统的完整性和用户体验。此版本标志着网盘系统在专业摄影文件支持方面的重要进步。

---

## ✨ 新功能

### 1. RAW格式照片预览支持
- **支持格式**: 尼康(.nef)、佳能(.cr2/.cr3)、索尼(.arw)、松下(.rw2)、奥林巴斯(.orf)、通用(.dng)
- **技术实现**: 使用rawpy库在后台解码RAW文件，生成JPEG预览图
- **预览存储**: 预览图存储在`media/previews/`目录，通过File模型的preview字段管理
- **自动生成**: 文件上传时自动触发预览生成，现有文件可通过脚本批量生成

### 2. 增强的文件预览功能
- **预览框优化**: 放大预览框尺寸，改善视觉体验
- **文件名处理**: 修复长文件名换行问题，使用Bootstrap的`text-break`类
- **文件图标**: 为RAW文件显示专用相机图标
- **预览逻辑**: 优先使用生成的预览图，无预览时显示文件图标

## 🔧 技术改进

### 后端改进
1. **File模型增强**
   - 添加`preview`字段存储预览图路径
   - 实现`generate_preview()`方法统一处理预览生成
   - 添加`preview_url`属性方法返回预览URL
   - 支持图像格式和RAW格式的预览生成

2. **RAW文件处理工具**
   - `_generate_raw_preview()`: 使用rawpy解码RAW文件
   - `_extract_embedded_preview()`: 提取RAW文件内嵌的JPEG预览
   - `_generate_image_preview()`: 处理常规图像文件预览

3. **错误处理优化**
   - 增强预览生成过程的异常处理
   - 添加详细日志记录便于调试
   - 修复临时文件锁定问题

4. **文件删除机制增强**
   - 重写File模型的delete方法，确保删除文件时同时删除预览图
   - 实现Django信号处理，在文件删除前清理关联文件
   - 双重保障机制防止预览图文件残留

### 前端改进
1. **文件列表页面优化**
   - 更新`templates/storage/file_list.html`
   - 添加预览图URL数据属性: `data-preview-url`
   - 扩展JavaScript预览逻辑支持RAW文件
   - 优化响应式布局

2. **用户界面修复**
   - 修复分享功能入口缺失问题
   - 优化导航栏布局
   - 改进移动端显示效果

## 🐛 问题修复

### 已修复的问题
1. **新上传文件无法预览**
   - 问题: 文件上传时预览生成失败
   - 修复: 优化预览生成逻辑，确保文件保存后正确触发预览生成
   - 验证: 测试确认JPEG、PNG、RAW文件都能正常生成预览

2. **文件名换行错误**
   - 问题: 长文件名在预览框中显示异常
   - 修复: 使用Bootstrap的`text-break`类实现自动换行

3. **预览框尺寸过小**
   - 问题: 预览框在较大屏幕上显示过小
   - 修复: 调整网格布局，将预览框从`col-lg-4`增加到`col-lg-5`

4. **分享功能入口缺失**
   - 问题: 创建分享链接功能在前端没有入口
   - 修复: 在文件列表操作按钮组、导航栏和预览区域添加分享按钮

5. **RAW文件删除后预览图残留**
   - 问题: 删除RAW文件时，生成的预览图文件未同步删除，导致磁盘空间泄漏
   - 修复: 实施双重保障机制：
     - **方案1**: 在File模型中重写delete方法，确保删除文件时同时删除预览图
     - **方案3**: 使用Django信号处理，在文件删除前清理关联文件
   - 验证: 测试确认所有文件删除路径都能正确清理预览图文件

## 📊 性能考虑

1. **预览图优化**
   - 尺寸限制: 最大800×800像素
   - 格式: JPEG，质量85%
   - 存储: 独立目录，便于管理

2. **处理策略**
   - 后台处理，不影响前端响应
   - 预览图缓存，避免重复生成
   - 错误降级，生成失败时显示文件图标

3. **资源占用**
   - RAW文件解码需要较多内存
   - 建议服务器配置至少2GB可用内存
   - 大型RAW文件处理可能需要较长时间

## 📝 注意事项

1. **RAW文件处理**
   - 首次处理大型RAW文件可能需要较长时间
   - 确保服务器有足够内存处理RAW文件解码
   - 建议定期清理未使用的预览图

2. **依赖兼容性**
   - rawpy库需要系统安装libraw
   - Windows用户可能需要安装Visual C++ Redistributable
   - 确保Python版本兼容性（推荐Python 3.8+）

3. **存储空间**
   - 预览图会占用额外存储空间
   - 建议监控`media/previews/`目录大小
   - 可配置定期清理策略
